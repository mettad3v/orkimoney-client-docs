The Orki Money Partner API provides a unified interface for discovering supported assets and providers, requesting quotes, creating ramp transactions, and retrieving transaction status.

## Base URLs

| Environment | Base URL |
| --- | --- |
| Production | `https://api.money.orki.io` |
| Sandbox | `https://sandbox.money.orki.io` |

Partner endpoints use the `/api/v1/partner` base path in both environments.

<Info>
Use TEST API keys with the sandbox base URL. Sandbox transactions are stored separately from LIVE transactions and do not initiate payment when the Orki transaction record and provider checkout link are created. The sandbox currently supports Transak staging quotes and checkout-session creation; do not assume that provider completion and webhook delivery are simulated end to end.
</Info>

## Authentication

Send your partner API key in the `X-ORKI-API-KEY` request header. See [API Authentication](/api-authentication/index) for an example.
